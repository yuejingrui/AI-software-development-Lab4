# 基础规则

1. 代码注释
   · 总是在代码中添加中文注释
   · 注释需标明函数、类等对象的功能
2. 变量命名
   · 采用驼峰命名法，保证清晰易读
   · 使用注释明确说明变量的含义
3. 代码结构
   · 结构清晰，段与段之间增加空行
4. 语法规范
   · 代码必须符合语法规范
5. 范围限制
   · 禁止生成与项目需求无关的代码
6. 文件访问
   · 不要打开或阅读与每次对话 prompt 无关的文件
7. 请你每次完成代码后，在一个README文件中持续更新目录中你创建的文件的功能与使用方式

# 项目要求

## 项目描述

实现一个前后端分离的智能出行规划器

## 技术栈

· 前端：Vue 3
· 后端：Python + FastAPI
· 数据存储：SQLite

## 安全与配置要求

· 严禁在前端代码中硬编码 API Key
· 前端通过请求后端接口获取所需数据
· API Key 在后端配置中获取，后端使用占位文件存储 API Key（不包含真实密钥）
· 开发者可通过替换文件名的方式使用真实的 API Key
