# 每日详情页验收清单

## 一、路由与页面

- [ ] `/day/:date` 路由存在并可访问。
- [ ] 点击日历日期后，首页左侧预览栏会刷新为该日期的任务，不直接跳转。
- [ ] 左侧预览栏存在独立的「查看完整详情 →」入口，可进入 `/day/YYYY-MM-DD`。
- [ ] 页面可通过 URL 直接访问（如 `/day/2026-06-02`）。

## 二、页面头部

- [ ] 显示当前日期（格式：YYYY年M月D日 星期X）。
- [ ] 显示当天总学习时长（分钟）。
- [ ] 存在"返回首页"按钮或入口。
- [ ] 存在"前一天"/"后一天"切换按钮。
- [ ] 切换到无任务的相邻日期时页面不报错，正常展示空状态。

## 三、任务列表

- [ ] 当天所有计划的任务完整展示。
- [ ] 多计划场景下按计划分组展示（每组有分组标题）。
- [ ] 无任务时展示空状态提示。
- [ ] 每个任务显示：所属计划名称、标签、标题、说明、预计时长。
- [ ] 每个任务显示完成状态 checkbox。
- [ ] 子任务查询异常时，主任务列表仍正常显示，不会整页变为空。

## 四、完成状态交互

- [ ] checkbox 勾选后任务视觉状态变化（删除线、颜色变淡）。
- [ ] 取消勾选后视觉状态恢复。
- [ ] 勾选/取消勾选后即时调用 API 持久化。
- [ ] 刷新页面后完成状态保留。
- [ ] 更新失败时 checkbox 回滚到原状态。
- [ ] 切换前一天/后一天后，完成状态与持久化数据一致。
- [ ] 返回首页后日历上的完成统计同步更新。

## 五、任务详情跳转

- [ ] 每日详情页中的任务可点击。
- [ ] 点击任务后跳转到对应计划详情页（`/plan/:planId`）。

## 六、子任务：手动创建

- [ ] 每个任务卡片下子任务列表末尾有「+ 添加子任务」输入框。
- [ ] 输入标题后回车，子任务即时显示在列表中。
- [ ] 空标题回车不创建子任务。
- [ ] 手动创建的子任务 `source` 为 `user`。
- [ ] 手动创建的子任务持久化到 `study_subtasks`。
- [ ] 刷新页面后手动创建的子任务及其来源标识保留。

## 七、子任务：手动修改与删除

- [ ] 每个子任务行末尾有编辑按钮。
- [ ] 点击编辑按钮后标题变为可编辑输入框。
- [ ] 修改标题后回车或失焦，即时更新显示并持久化。
- [ ] 每个子任务行末尾有删除按钮。
- [ ] 点击删除按钮后子任务即时移除并持久化删除。

## 八、子任务：AI 拆分

- [ ] 每个任务卡片下方有「AI 拆分子任务」按钮。
- [ ] 点击按钮后显示 loading 状态，防止重复点击。
- [ ] AI 成功生成 3-5 个 `source='ai'` 的子任务。
- [ ] 已有子任务时按钮文案变为「重新拆分」。
- [ ] **「重新拆分」仅删除 `source='ai'` 的旧子任务，保留 `source='user'` 的用户手动创建的子任务。**
- [ ] AI 拆分失败时显示错误 toast 提示，可再次点击重试。
- [ ] 无 DEEPSEEK_API_KEY 时，使用 fallback 生成 3 个固定模板子任务。

## 九、子任务：完成交互

- [ ] 每个子任务有独立 checkbox。
- [ ] 子任务勾选后文字显示删除线 + 颜色变淡。
- [ ] 子任务取消勾选后视觉状态恢复。
- [ ] 子任务完成状态持久化到 CloudBase `study_subtasks`。
- [ ] 刷新页面后子任务完成状态保留。
- [ ] 显示子任务完成进度（如「已完成 2/3 步」）。
- [ ] 更新子任务失败时 checkbox 回滚。

## 十、子任务：级联规则

- [ ] 所有子任务勾选完成后，父任务自动标记为完成。
- [ ] 父任务被勾选为完成时，所有子任务自动标记为完成。
- [ ] 取消父任务完成时，子任务保持当前状态不变。

## 十一、数据持久化

- [ ] `study_subtasks` 集合存在且数据正确写入。
- [ ] `generateSubtasks` API 正常工作且仅替换 AI 子任务。
- [ ] `createSubtask` API 正常工作且 `source='user'`。
- [ ] `updateSubtask` API 正常工作。
- [ ] `deleteSubtask` API 正常工作。
- [ ] `updateSubtaskStatus` API 正常工作并更新完成状态。
- [ ] `getTasksByDate` API 返回的每个任务包含 `subtasks` 字段。

## 十二、异常与边界

- [ ] 访问不存在的日期不报错（显示正常空状态）。
- [ ] 访问格式错误的日期（如 `/day/abc`）有友好提示或重定向。
- [ ] 网络请求失败时有错误提示。
- [ ] 页面加载中有 loading 状态。
- [ ] 无任务的日期不显示子任务相关 UI。
- [ ] 全部为 AI 子任务时「重新拆分」正常覆盖。
- [ ] 混合来源（用户+AI）时「重新拆分」仅替换 AI 子任务，用户子任务保留且排序正确。
- [ ] `study_subtasks` 集合缺失、无排序索引或排序查询失败时，`getTasksByDate` 仍返回主任务，子任务降级为空或普通排序结果。
