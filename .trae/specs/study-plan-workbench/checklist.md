# 学习计划工作台验收清单

## 一、计划创建

- [ ] 首页存在“新建学习计划”入口。
- [ ] 表单至少包含目标或学习内容、开始日期、结束日期字段。
- [ ] 表单包含每日可用时长、描述/补充说明、参考资料与平台、用户身份、预期学习成果/程度、主题标签、备注等扩展字段。
- [ ] 必填项为空时禁止提交并显示错误提示。
- [ ] 结束日期早于开始日期时禁止提交。
- [ ] 每日可用时长输入非法时禁止提交。
- [ ] 标签名称超过 10 字时禁止提交。
- [ ] 提交后有加载状态，避免重复提交。
- [ ] 创建成功后用户能看到成功反馈。
- [ ] 创建成功后可直接进入计划详情页。

## 二、AI 补全与生成

- [ ] 前端可在提交前检查非必要信息是否为空。
- [ ] 对于空的非必要字段，系统会调用 AI 生成简短建议值。
- [ ] AI 建议值会回填到表单中，并允许用户修改或忽略。
- [ ] 前端可调用云函数创建学习计划。
- [ ] 云函数会调用 DeepSeek-V4-Flash 生成结构化逐日任务。
- [ ] AI 生成任务时会考虑目标日期中已有的任务安排。
- [ ] 云函数会校验 AI 输出结构，避免写入非法数据。
- [ ] 计划信息被保存到 `study_plans` 集合。
- [ ] 逐日任务被保存到 `study_tasks` 集合。
- [ ] AI 补全过程结果会被保存。
- [ ] 创建第二份、第三份计划后，旧计划不会被覆盖。

## 三、多个计划管理

- [ ] 首页底部可查看全部计划摘要。
- [ ] 每份计划至少展示主题或目标摘要、起止日期、标签、任务进度。
- [ ] 多份计划可以同时存在并被读取。
- [ ] 点击概览项后可进入该计划的详情页。

## 四、统一日历展示

- [ ] 系统只使用一个统一日历展示全部计划任务。
- [ ] 同一天来自多个计划的任务会聚合到同一日期格。
- [ ] 非当前选中日期的日期格显示任务总数。
- [ ] 当前选中日期的日期格显示已完成数量 / 总数量。
- [ ] 日期格不显示主题摘要文本。
- [ ] 日期格仅展示标签色块，并能区分不同标签颜色。

## 五、每日任务详情

- [ ] 点击某一天后可以查看当天任务详情。
- [ ] 页面一左侧用于展示选中日期的任务详情。
- [ ] 详情中能看到当天所有计划的任务。
- [ ] 每条任务可显示所属计划主题、标签、任务标题、说明、预计时长。
- [ ] 当天无任务时有空状态提示。

## 六、完成状态记录

- [ ] 用户可勾选某条任务为完成。
- [ ] 用户可取消已完成状态。
- [ ] 更新后 UI 会即时刷新。
- [ ] 完成状态更新会写入 CloudBase。
- [ ] 页面刷新后完成状态仍然保留。
- [ ] 日历上的完成统计会随着状态变化同步更新。

## 七、任务动态调整与 AI 优化

- [ ] 用户可手动修改任务标题、说明、预计时长、日期或标签。
- [ ] 用户修改后的任务信息会持久化到 CloudBase。
- [ ] 存在计划详情页用于展示单个计划的完整信息。
- [ ] 新建计划成功后可进入计划详情页。
- [ ] 点击概览列表中的计划后可进入计划详情页。
- [ ] 计划详情页支持与 AI 对话以改进任务规划。
- [ ] AI 对话生成的建议可预览并应用。

## 八、异常处理

- [ ] AI 生成失败时，页面能提示失败原因或重试建议。
- [ ] AI 补全失败时，用户仍可使用已有信息继续创建计划。
- [ ] 网络失败时，页面能提示请求失败。
- [ ] 更新任务状态失败时，页面会回滚勾选结果。
- [ ] 更新任务信息失败时，页面能提示保存失败。
- [ ] 日历无任务数据时，页面不会报错。

## 九、技术栈符合性

- [ ] 前端使用 Vue 3 + Composition API。
- [ ] 前端使用 TypeScript。
- [ ] 项目使用 Vite 6。
- [ ] 后端运行在 Node.js 18.15 的 CloudBase 云函数环境。
- [ ] 数据存储使用 CloudBase 文档数据库。
- [ ] AI 模型使用 DeepSeek-V4-Flash。
- [ ] 联网检索使用 DuckDuckGo Instant Answer API。
- [ ] 部署目标为腾讯云 CloudBase 静态托管与云函数。

## 十、基础版完成判定

- [ ] 能以“少量必填 + AI 补全可选信息”的方式创建计划。
- [ ] 能创建并保存多份学习计划。
- [ ] 能在统一日历中展示所有计划任务。
- [ ] 能查看某一天的全部学习任务。
- [ ] 能标记完成并在刷新后保留。
- [ ] 能进入计划详情页并继续优化任务信息。
- [ ] 整体流程形成“创建 -> AI 补全 -> 展示 -> 查看 -> 勾选 -> 调整 -> 持久化”的完整闭环。
