# 学习计划工作台开发任务拆分

## 阶段 1：项目初始化

- [ ] 使用 Vite 6 初始化 Vue 3 + TypeScript 项目。
- [ ] 配置基础目录结构：`components`、`views`、`services`、`types`、`composables`。
- [ ] 配置 CloudBase 前端 SDK 与环境变量。
- [ ] 建立公共请求封装与错误处理工具。

## 阶段 2：数据结构与接口定义

- [ ] 定义 `StudyPlan`、`StudyTask`、`CalendarDaySummary` 等 TypeScript 类型。
- [ ] 定义 `TagView`、`PlanChatMessage`、`AiSupplementResult` 等类型。
- [ ] 约定前后端共享的数据字段命名。
- [ ] 设计云函数入参与出参结构。
- [ ] 约定 AI 返回 JSON Schema。

- [ ] 在 `createStudyPlan` 中接入 DeepSeek-V4-Flash。

- [ ] 在 `createStudyPlan` 中查询目标日期范围内已有任务，用于平衡新计划的日程负载。

## 阶段 4：前端页面与组件

### 4.1 工作台首页
- [ ] 搭建工作台主页面布局。
- [ ] 放置页面标题、新建计划按钮、左侧日期详情区、统一日历区、底部计划概览区。

### 4.2 创建计划
- [ ] 实现新建计划弹窗或表单面板。
- [ ] 完成“目标/学习内容 + 起止时间”为必填的表单设计。
- [ ] 增加每日可用时长、参考资料与平台、用户身份、预期学习成果、主题标签、备注等选填字段。
- [ ] 实现标签颜色选择或自动分配逻辑。
- [ ] 完成字段输入与表单校验。
- [ ] 实现 AI 补全建议预览与确认交互。
- [ ] 接入 `createStudyPlan` 云函数。
- [ ] 创建成功后自动刷新计划列表与日历数据，并跳转计划详情页。

### 4.3 计划概览
- [ ] 实现计划摘要列表组件。
- [ ] 展示主题、起止日期、标签、进度信息。
- [ ] 支持点击概览项进入计划详情页。

### 4.4 统一日历
- [ ] 实现月视图日历组件。
- [ ] 将同一天来自多个计划的任务聚合展示。
- [ ] 在当前选中日期显示已完成数量 / 总数量。
- [ ] 在其他日期显示任务总数。
- [ ] 在日期格中显示标签色块而不是主题摘要文本。
- [ ] 支持切换月份并加载对应范围数据。

### 4.5 每日任务详情
- [ ] 实现点击日期后在左侧展开的任务详情面板。
- [ ] 展示当天所有任务及所属计划信息。
- [ ] 支持空状态展示。

### 4.6 任务完成状态
- [ ] 为每条任务实现完成状态复选框。
- [ ] 接入 `updateTaskStatus` 云函数。
- [ ] 更新成功后同步刷新详情与日历汇总状态。
- [ ] 更新失败时执行 UI 回滚。

### 4.7 计划详情与 AI 优化页
- [ ] 搭建页面二：计划详情与 AI 优化页。
- [ ] 展示单个计划的完整信息、标签、AI 补全来源。
- [ ] 展示该计划的全部任务列表与任务详细信息。
- [ ] 接入 `getPlanDetail` 云函数。
- [ ] 实现 AI 对话面板。
- [ ] 接入 `refinePlanWithAI` 与 `savePlanChatMessage` 云函数。

### 4.8 任务动态调整
- [ ] 为任务实现标题、说明、预计时长、日期、标签的编辑能力。
- [ ] 接入 `updateTaskInfo` 云函数。
- [ ] 支持 AI 建议调整的预览与应用。

## 阶段 5：状态管理与数据流

- [ ] 使用 Composition API 组织页面级状态。
- [ ] 管理当前月份、当前选中日期、计划列表、当天任务、当前计划详情、AI 对话状态、加载状态。
- [ ] 封装获取计划列表、获取日历数据、获取某日任务、获取计划详情的方法。
- [ ] 处理创建计划后、切换月份后、更新任务后、AI 优化后的一致性刷新逻辑。

## 阶段 6：稳定性与体验优化

- [ ] 为加载中、空状态、错误状态提供清晰反馈。
- [ ] 防止创建计划和更新任务时重复点击。
- [ ] 为 AI 补全建议标注“建议值”，避免误解。
- [ ] 优化 AI 生成失败时的报错文案。
- [ ] 优化 AI 对话建议应用失败时的提示逻辑。
- [ ] 对日期聚合逻辑进行边界测试。

## 阶段 7：测试与验收

- [ ] 手动验证“创建第一份计划 -> AI 补全 -> 日历展示 -> 查看详情 -> 勾选完成 -> 刷新保留”闭环。
- [ ] 手动验证创建多份计划后的统一日历聚合效果。
- [ ] 手动验证同一天有多个计划任务时的展示。
- [ ] 手动验证标签色块展示与当前选中日期统计规则。
- [ ] 手动验证进入计划详情页后与 AI 对话优化任务规划。
- [ ] 手动验证手动编辑任务后的持久化结果。
- [ ] 手动验证异常场景：AI 失败、网络失败、状态更新失败。
- [ ] 对关键工具函数补充单元测试，如日期映射、聚合统计、进度计算。

## 推荐实施顺序

1. 先打通云函数与数据库，确保“AI 补全 + 创建计划 + 读取任务”可用。
2. 再实现统一日历与左侧日期详情，优先展示聚合结果。
3. 然后实现计划详情页、任务编辑和 AI 对话优化。
4. 最后补齐异常处理、体验优化和测试。
