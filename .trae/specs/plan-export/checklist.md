# 计划导出验收清单

## 一、单个计划导出

- [x] 计划详情页存在「导出」按钮，点击后显示下拉菜单选择格式（Markdown / TXT）。
- [x] 选择 Markdown 导出后浏览器弹出保存对话框（支持 showSaveFilePicker 的浏览器）。
- [x] 选择 TXT 导出后浏览器弹出保存对话框。
- [x] Markdown 导出文件包含计划名称、日期范围、总天数、总/已完成任务数。
- [x] Markdown 导出按日期分组，使用 `#` 标题、`- [x]`/`- [ ]` 列表、`>` 引用块语法。
- [x] TXT 导出使用纯文本格式，无 Markdown 标记符号，以 `===` 和 `---` 分隔。
- [x] 每个任务包含：标题、描述、预计时长、完成状态。
- [x] 空任务计划导出时包含基本信息和"该计划暂无学习任务"。
- [x] 文件名默认使用计划名称（非法字符已替换为 `_`），后缀正确（`.md` 或 `.txt`）。
- [x] 不支持 `showSaveFilePicker` 的浏览器回退到浏览器默认下载行为。

## 二、全部计划导出

- [x] 首页顶部栏存在「导出全部计划」按钮，点击后下拉选择格式。
- [x] 无活动计划时该按钮不显示。
- [x] Markdown 导出包含所有计划的名称、日期和任务，以分隔线区分。
- [x] TXT 导出包含所有计划信息，纯文本格式。
- [x] 单个计划加载失败时跳过，不影响其他计划导出。
- [x] 默认文件名为 `全部学习计划_YYYY-MM-DD.md` 或 `.txt`。
- [x] 导出内容包含导出时间戳。

## 三、格式切换与路径选择

- [x] 导出格式切换正确生成对应格式内容（MD 含 Markdown 标记，TXT 不含）。
- [x] `showSaveFilePicker` 支持的浏览器弹出原生保存对话框，可自定义路径和文件名。
- [x] `saveFile` 降级逻辑在 Edge/Chrome 旧版本上正常工作（传统下载）。

## 四、边界情况

- [x] 计划名含 `/` `\` `:` 等字符时文件名自动替换为 `_`。
- [x] 计划无任务时导出不报错且有"暂无任务"提示。
- [x] 页面计划数为 0 时导出按钮不渲染。
- [x] 导出过程中显示 loading 状态，完成后恢复。
- [x] 导出的 MD 文件可在 Typora / VS Code 中正常渲染。
- [x] 导出的 TXT 文件可在记事本中正常打开，中文字符无乱码。
