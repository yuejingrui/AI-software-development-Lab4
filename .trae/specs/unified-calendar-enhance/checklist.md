# 统一日历增强验收清单

## 一、日历日期格增强

- [ ] 当日所有任务完成时，日期格显示绿色背景。
- [ ] 当日部分任务完成时，日期格显示橙色背景。
- [ ] 当日无任务时，日期格为默认样式。
- [ ] 当前选中日期有蓝色边框高亮。
- [ ] "今天"日期（实际当前日期）有特殊显示（如蓝色加粗数字）。
- [ ] 标签色块正确展示且去重。
- [ ] 日期格不显示学习时长（仅任务数量 + 标签色块）。
- [ ] 切换月份后，状态和选中高亮正确刷新。

## 二、空状态引导

- [ ] 无任何学习计划时，页面底部计划概览列表区域显示引导提示。
- [ ] 引导提示不显示在日历区域。
- [ ] 引导提示包含引导性文案。
- [ ] 创建计划后引导提示自动消失。

## 三、全局统计面板

- [ ] 统计面板显示总计划数（与实际计划数量一致）。
- [ ] 统计面板显示总学习天数（与实际去重日期数量一致）。
- [ ] 统计面板显示总学习时长（分钟转小时，与实际求和一致）。
- [ ] 统计面板显示全局完成率（百分比，与实际完成数/总数一致）。
- [ ] 创建/删除计划或更新任务状态后统计面板数据同步刷新。
